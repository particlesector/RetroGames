# DRYLINE Grand Prix

A single-screen, top-down racing game for the NES in which rain soaks the track
and the cars dry a line through it.

**Status: pitch.** No game code yet. See the [pitch](docs/pitch/PITCH.md) and
the [dev log](docs/devlog/).

Regenerate the pitch art with `python3 tools/pitch/make_mock.py` (needs Pillow and numpy).
