# A song: a header, its phrases, then its order.
#   song NAME       title shown on the title screen (letters, digits, space)
#   tempo F         frames an eighth note lasts (16: 112.5 beats a minute)
#   sky THEME       dusk, night, gale or dawn
#   beat N          the bass and drum pattern (0-3, below)
#   phrase ID       then bars of exactly 8 eighths, one per line:
#     CHORD | t t t t t t t t
#   order ID ID ... the phrases played in turn
#
# Chords: C F Am Bb G (the bass's root: C2 F2 A2 Bb2 on the buzzy waveform, G3 on the pure one).
# Melody tokens: a note (C4 D4 E4 A4 C5 D5 E5 G5 A5 C6: the notes the TIA plays in tune),
# - holds the note before, . rests. Each note is a chime.
#
# Beats (eighths 0-7): 0 bass on 0 2 4 6, snare on 3 and 7
#                      1 bass on 0 and 4, snare on 2 and 6 (half time)
#                      2 bass on every eighth, snare on 4 (driving)
#                      3 bass on 0 3 6, no snare (lilting)
